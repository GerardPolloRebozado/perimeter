# Spike 1 notes: Java + Spring Boot

**Code:** this directory — a Gradle project colocated with these notes

## Timebox

**3 hours, agreed by the whole team before any code was written — the full target was reached inside it.** The same length for every technology so we could not quietly favour the one we already liked: long enough to absorb toolchain setup (Gradle download, first build) and still implement the target plus tests; short enough that stopping when the timer rings costs little.

When time ran out we were past the target: `:8080/ping` returning exactly `{"status":"ok"}` with the port read only from `PORT`, and 4 tests passing. The remaining minutes went into the CORS config and this file.

## What was built

| File | Role |
|---|---|
| `build.gradle.kts` | Generated by Spring Initializr: Spring Boot **4.1.2**, Java 17, one starter: `spring-boot-starter-webmvc` |
| `src/main/resources/application.properties` | `server.port=${PORT}`: port only from the env var, **no default** |
| `src/main/java/com/area/spike2/ping/PingController.java` | `GET /ping` → `PingResponse.ok()` |
| `src/main/java/com/area/spike2/ping/PingResponse.java` | `record PingResponse(String status)`, which Jackson turns into `{"status":"ok"}` |
| `src/main/java/com/area/spike2/ping/WebConfig.java` | CORS: lets the KMP web client (`http://localhost:8081`, configurable with `CORS_ALLOWED_ORIGINS`) call the API from a browser |
| `src/main/java/com/area/spike2/ping/Spike2JavaSpringApplication.java` | Generated entry point (unchanged) |
| `src/test/java/.../PingControllerTest.java` | Exact body + JSON content type, CORS allowed for 8081, rejected for other origins |
| `src/test/resources/application.properties` | `server.port=0` so tests don't need `PORT` |

## How to run it

```sh
cd spikes/2/java-spring
./gradlew test                     # 4 tests
PORT=8080 ./gradlew bootRun        # or: ./gradlew bootJar && PORT=8080 java -jar build/libs/spike2-java-spring-0.0.1-SNAPSHOT.jar
curl -i http://localhost:8080/ping
```

## Observations

- **Developer velocity:** very little code for the target (one controller, one record, one property). Annotations hide a lot, so it's fast to write but you need to know which annotation does what.
- **Spring Boot 4 changes:** the web starter is now `spring-boot-starter-webmvc` (it used to be `-web`). Many tutorials online are still for Boot 3.
- **Error clarity:** when `PORT` is missing, the error is `Failed to bind properties under 'server.port' … For input string: "${PORT}"`. It's correct, but it doesn't plainly say "env var PORT is missing".
- **Ecosystem:** CORS took one small config class. OpenAPI (springdoc), OAuth2 client and `@Scheduled` all exist as official or well-known modules, but weren't tried in this spike.
- **First build cost:** ~1 min (Gradle download), then ~10 s per build.
